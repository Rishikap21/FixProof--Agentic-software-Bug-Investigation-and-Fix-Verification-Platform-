BUG-001: Incorrect Shopping Cart Total

The shopping cart displays an incorrect total when multiple products are added. The application calculates the price using only one product instead of adding all product prices.

Pending Review

1. Original Code

BEFORE PROPOSED FIX

// Original calculation function calculateTotal(products) { return products[0].price; }

2. Proposed Code Patch

AFTER PROPOSED FIX

// Proposed calculation function calculateTotal(products) { return products.reduce( (total, product) => total + product.price, 0 ); }

3. Change Summary

Explanation:

The original function returns only the first product's price. The proposed implementation uses the reduce() method to calculate the sum of all product prices.


Expected improvement:
  • Calculates the total of multiple products.
  • Supports an empty product list with a total of zero.
  • Provides a more accurate shopping cart calculation.
